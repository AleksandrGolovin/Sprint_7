# Sprint_7

### Проект автотестов для API сервиса доставки самокатов

Проект включает тесты для проверки функционала:
- Создания/удаления курьеров
- Логина курьеров
- Создания заказов
- Управления заказами

---

### Тестовые классы и тесты

#### 1. `TestCreateOrder` (`test_create_order.py`)
- **Тест**: Создание заказа с разными цветами самокатов  
  Проверяет код 201 и наличие track ID для цветов:  
  `["BLACK"]`, `["GREY"]`, `["BLACK", "GREY"]`, `[]`

#### 2. `TestGetOrders` (`test_get_orders.py`)
- **Тест 1**: Получение разного количества заказов (1, 10, 30)  
  Проверяет код 200 и соответствие длины списка заказов
- **Тест 2**: Получение заказов с разных страниц (0, 3, 10)  
  Проверяет код 200 и непустой список заказов
- **Тест 3**: Получение заказов курьера  
  Проверяет увеличение списка заказов после назначения курьеру

#### 3. `TestCreateCourier` (`test_create_courier.py`)
- **Тест 1**: Создание курьера с уникальными данными  
  Ожидает код 201 и сообщение `{"ok":true}`
- **Тест 2**: Создание дубликата курьера  
  Ожидает код 409 и сообщение об ошибке
- **Тест 3**: Создание с неполными данными  
  Проверяет код 400 и сообщение для 3 случаев невалидных данных

#### 4. `TestDeleteCourier` (`test_delete_courier.py`)
- **Тест 1**: Удаление с валидным ID  
  Ожидает код 200 и `{"ok":true}`
- **Тест 2**: Удаление без ID  
  Ожидает код 404 (расхождение с документацией)
- **Тест 3**: Удаление с несуществующим ID  
  Ожидает код 404 и сообщение об ошибке

#### 5. `TestLoginCourier` (`test_login_courier.py`)
- **Тест 1**: Логин с валидными данными  
  Ожидает код 200 и наличие ID в ответе
- **Тест 2**: Логин с неполными данными  
  Ожидает код 400 и сообщение об ошибке
- **Тест 3**: Логин с несуществующими данными  
  Ожидает код 404 и сообщение об ошибке
- **Тест 4**: Логин с неверным паролем  
  Ожидает код 404 и сообщение об ошибке

---

### Фикстуры (`conftest.py`)
1. `orders_methods`  
   Инициализирует методы работы с заказами:  
   `BASE_URL + ORDERS_URL`
2. `courier_methods`  
   Инициализирует методы работы с курьерами:  
   `BASE_URL + COURIER_URL`
3. `authorized_courier`  
   - Создает курьера со случайными данными
   - Выполняет логин
   - Возвращает объект ответа с ID
   - Удаляет курьера после теста

### Вспомогательные функции (`helpers.py`)
**`generate_courier_data()`**  
Генерирует случайные данные курьера:
- `login`: 16 строчных букв
- `password`: 10 строчных букв
- `firstName`: 16 строчных букв

Пример возвращаемых данных:
```python
{
    "login": "abcdefghijklmnop",
    "password": "qwertyuiop",
    "firstName": "asdfghjklzxcvbnm"
}
```

### Запуск тестов
1. Установите зависимости (pytest, allure-pytest, requests)

2. Запустите тесты:
```bash
pytest --alluredir=allure-results
```

3. Отчет Allure:
```bash
# Генерация отчета
allure generate allure-results --clean -o allure-report

# Открытие в браузере
allure open allure-report
```
